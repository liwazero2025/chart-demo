### 阶段二：全栈能力突破（第 2-3 个月）

**目标**：独立完成后端 API 开发，实现 chart-demo 全栈化

#### 核心书目
| 优先级 | 书名 | 作者 | 重点章节 | 学习方式 |
|-------|------|------|---------|---------|
| ⭐⭐⭐ | 《Node.js 设计模式》 | Mario Casciaro | 异步编程、流、模块系统、设计模式 | 精读 + 实践 |
| ⭐⭐⭐ | 《设计数据密集型应用》 | Martin Kleppmann | 数据模型、存储引擎、编码演化 | 精读（重点 1-5 章） |
| ⭐⭐ | 《HTTP 权威指南》 | David Gourley | HTTP 协议、缓存、安全 | 查阅式阅读 |

#### 公开课/视频
- [ ] **Node.js 官方文档动手实验**：流、事件循环
- [ ] **极客时间：Node.js 开发实战**（狼叔）：Web 框架、数据库
- [ ] **Udemy：Node.js, Express, MongoDB Bootcamp**（Jonas Schmedtmann）

#### 技术选型
| 层级 | 技术 | 理由 |
|-----|------|------|
| 运行时 | Node.js 20 LTS | 你最熟悉的语言，生态成熟 |
| 框架 | Express 或 Fastify | Express 简单，Fastify 性能更好 |
| 数据库 | PostgreSQL | 关系型数据库标准，SQL 技能必备 |
| ORM | Prisma | TypeScript 友好，类型安全 |
| 缓存 | Redis | 会话存储、热点数据缓存 |
| 鉴权 | JWT + bcrypt | 行业标准方案 |

#### 实战任务：chart-demo 全栈改造

```
改造目标
├── 后端 API (Node.js + Express)
│   ├── POST /api/charts - 保存图表配置
│   ├── GET /api/charts/:id - 读取图表配置
│   ├── GET /api/charts - 列表（分页）
│   ├── PUT /api/charts/:id - 更新配置
│   ├── DELETE /api/charts/:id - 删除配置
│   └── POST /api/auth/* - 用户注册/登录/刷新 Token
│
├── 数据库 (PostgreSQL)
│   ├── charts 表 - 图表配置 JSONB 存储
│   ├── users 表 - 用户信息
│   └── user_chart_access - 权限关联
│
├── 前端改造
│   ├── 添加登录/注册页面
│   ├── 图表配置保存/读取功能
│   └── 用户个人中心（历史记录）
│
└── 部署
    ├── Docker 容器化
    └── 云服务器部署 (AWS/阿里云/腾讯云)
```
